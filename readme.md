# another try to write useful bot

Мультисервисный проект: набор сервисов для выполнения рутинных операций через Telegram.

## notes — /note task

Сервис `notes` умеет отвечать на команду `/note task`: читает markdown-файл задач, парсит его,
фильтрует по аргументу команды и возвращает отформатированный список (или предупреждения о
нераспознанных строках).

Поведение настраивается в `notes/conf/notes_config.yaml`:

- `task_file_path` — путь к файлу задач относительно репозитория (default `"My Long Tasks List.md"`).
- `task_stop_marker` — строка-маркер, на которой парсинг задач останавливается; всё после неё
  (например, раздел Long Tasks) игнорируется (default `"### Long"`).
- `task_default_behavior` — фильтр, применяемый, когда аргумент команды пуст. Допустимые значения:
  `list` (все задачи), `due` (с датой), `today` (секция Today + просроченные), `due today`
  (просроченные и на сегодня), `warn` (только предупреждения). Парсер понимает эти же значения
  в аргументе команды (default `"today"`).
